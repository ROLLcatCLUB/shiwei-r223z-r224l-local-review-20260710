## Policy

The v0.2 candidate is locked as a candidate, not published as a formal standard.

It must not:

- overwrite R223M-P5 v0.1;
- automatically enter the formal generation chain;
- change prompts;
- call provider/model/runtime;
- write database records;
- write back lesson bodies;
- modify canonical teacher manuscripts;
- modify R97B;
- become formal apply behavior.

## Allowed Uses

v0.2 candidate evidence may be used only for:

1. opt-in sandbox review;
2. review-only pilot gate;
3. further regression fixtures;
4. schema / ledger / field review packages;
5. planning documents for later stage decisions.

## Review Requirements Before Publication

Any future move from candidate to published standard must show:

- cross-sample regression evidence;
- no regression to M/N/O canonical teacher manuscripts;
- stable review ledger traceability;
- clear source evidence versus system inference separation;
- explicit teacher confirmation boundaries;
- no prompt/model/runtime/db dependency unless separately authorized.
