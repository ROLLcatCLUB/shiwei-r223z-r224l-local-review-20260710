# R224C Router Effect On Teacher Manuscript Rules

stage_id: 1013R_R224C_ROUTER_TO_EVENT_EXPANSION_CONTRACT

## Rule

Router output affects the teacher default manuscript as teaching rhythm, not as visible field labels.

## Must Not Display

Teacher default manuscript must not display:

- unit_phase_role;
- lesson_position_in_unit;
- practice_intensity;
- student_work_time_ratio;
- teacher_support_density;
- router_effect;
- performance_task_link;
- stage_evidence_link.

## Must Express Naturally

### intro_understanding

Teacher manuscript should show:

- observation entry;
- comparison and naming;
- short student expression;
- evidence of understanding.

It should not expand into long creation blocks.

### technique_preparation

Teacher manuscript should show:

- teacher demonstration;
- small trial;
- method comparison;
- learning sheet record;
- modest product expectation.

### practice_creation

Teacher manuscript should show:

- clear task release;
- longer student work time;
- teacher circulation and rescue;
- process evidence capture;
- selected showcase and explanation.

High support should appear as teacher observation and timely help, not as more whole-class lecture.

### showcase_evaluation

Teacher manuscript should show:

- display or work selection;
- student explanation;
- peer/self evaluation;
- criteria-based evidence collection.

### transfer_closure

Teacher manuscript should show:

- transfer to life/new context/performance task;
- synthesis of earlier evidence;
- clear closure language.

### project_synthesis

Teacher manuscript should show:

- assembling prior evidence;
- completing the performance product;
- presenting rationale;
- evaluating against unit task.

## Manuscript Guard

R224C does not rewrite existing R223M/N/O teacher manuscripts. It only defines rules for future generation or regression.
