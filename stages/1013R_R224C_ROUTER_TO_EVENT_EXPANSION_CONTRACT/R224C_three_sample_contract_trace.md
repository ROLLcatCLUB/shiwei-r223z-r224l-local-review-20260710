# R224C Three Sample Contract Trace

stage_id: 1013R_R224C_ROUTER_TO_EVENT_EXPANSION_CONTRACT

## M. 我为文具代言

Router:

```text
late / practice_creation / high / high / heavy
```

Contract trace:

- event density: creation-serving events;
- explanation: medium, only for task purpose and key reminders;
- demonstration: targeted or rescue only;
- micro-practice: 1-2 bottleneck practices;
- formal creation time: high;
- teacher circulation: material choice, use problem, collaboration, process evidence;
- screen/sheet/evidence: task reminder, process photo, design reason, showcase explanation.

Teacher default manuscript effect:

The manuscript should read as a late-unit creation lesson with sustained work time and teacher support, not as an introductory lecture.

## N. 有趣的纸印

Router:

```text
middle / technique_preparation / medium / medium / normal
```

Contract trace:

- event density: medium, trial-focused events;
- explanation: medium;
- demonstration: comparison-oriented;
- micro-practice: 2-3 trials;
- formal creation time: medium;
- teacher circulation: paper texture, color amount, pressure, peeling, trial record;
- screen/sheet/evidence: method steps, trial sample, print-method comparison, learning sheet record.

Teacher default manuscript effect:

The manuscript should read as a technique-preparation lesson with controlled trial and method evidence, not a final artwork pressure lesson.

## O. 色彩的碰撞

Router:

```text
early / intro_understanding / medium / medium / normal
```

Contract trace:

- event density: few-to-medium clear events;
- explanation: medium;
- demonstration: medium, focused on color relation and safe mixing;
- micro-practice: 2 color trials;
- formal creation time: medium but not heavy;
- teacher circulation: color ratio, warm/cool tendency, brightness, naming, visual feeling;
- screen/sheet/evidence: life color images, color trial, naming note, small expression.

Teacher default manuscript effect:

The manuscript should read as an early-unit visual understanding lesson. It should not become a heavy painting product lesson or a pure science experiment.
