# R224C Event Density Rules By Unit Phase Role

stage_id: 1013R_R224C_ROUTER_TO_EVENT_EXPANSION_CONTRACT

## intro_understanding

Event density should be few and clear.

Main events:

- observe a life/art/example source;
- compare key differences;
- name or describe what is noticed;
- record understanding evidence.

Avoid:

- heavy making;
- long product work;
- technique drills that are not needed yet.

## technique_preparation

Event density should be medium and trial-focused.

Main events:

- teacher demonstrates a key method;
- students try a small sample;
- class compares method effects;
- students record trial evidence.

Avoid:

- turning trials into final product pressure;
- overloading the lesson with too many techniques.

## practice_creation

Event density should serve student creation.

Main events:

- release making/design task clearly;
- protect sustained work time;
- teacher circulates and rescues bottlenecks;
- collect process and product evidence;
- showcase selected evidence.

Avoid:

- whole-class over-explanation;
- teacher-made model replacing student work.

## showcase_evaluation

Event density should support critique and evidence collection.

Main events:

- select/show works;
- explain intention or method;
- peer/self evaluate with criteria;
- collect evaluation evidence.

Avoid:

- empty praise;
- display without criteria.

## transfer_closure

Event density should support migration and unit closure.

Main events:

- revisit what has been learned;
- connect to life/use/new context;
- finish or explain performance task contribution;
- collect transfer evidence.

Avoid:

- opening a new heavy creation task without unit need.

## project_synthesis

Event density should coordinate prior evidence into performance product.

Main events:

- assemble prior drafts/trials/records;
- complete project product;
- explain rationale;
- evaluate product against performance task.

Avoid:

- isolated activities disconnected from previous evidence.
