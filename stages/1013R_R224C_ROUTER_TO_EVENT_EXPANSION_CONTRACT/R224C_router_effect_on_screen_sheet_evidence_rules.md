# R224C Router Effect On Screen Sheet Evidence Rules

stage_id: 1013R_R224C_ROUTER_TO_EVENT_EXPANSION_CONTRACT

## Rule

Router output must change screen, learning sheet, and evidence expectations.

## intro_understanding

Screen:

- observation image;
- comparison image;
- vocabulary / naming prompt.

Learning sheet:

- observation record;
- comparison note;
- short expression.

Evidence:

- oral expression;
- observation note;
- naming or classification record.

## technique_preparation

Screen:

- method step image;
- before/after or method comparison;
- common mistake / rescue image if needed.

Learning sheet:

- trial prediction;
- method record;
- comparison result.

Evidence:

- trial sample;
- method comparison note;
- small work or partial result.

## practice_creation

Screen:

- task reminder;
- selected process comparison;
- rescue demonstration;
- evidence checklist.

Learning sheet:

- plan;
- material choice;
- problem solved;
- process adjustment;
- peer suggestion.

Evidence:

- process photo;
- draft;
- finished or partial work;
- oral design explanation.

## showcase_evaluation

Screen:

- work wall;
- evaluation criteria;
- sentence frames for critique.

Learning sheet:

- self-evaluation;
- peer feedback;
- evidence selection.

Evidence:

- evaluation form;
- work explanation;
- peer/self assessment.

## transfer_closure

Screen:

- transfer task;
- life/use scenario;
- performance task summary.

Learning sheet:

- transfer note;
- unit reflection;
- use suggestion.

Evidence:

- transfer response;
- suggestion text;
- performance task contribution.

## project_synthesis

Screen:

- product assembly checklist;
- evidence chain view;
- presentation prompt.

Learning sheet:

- evidence selection;
- product rationale;
- revision note.

Evidence:

- final product;
- supporting evidence set;
- presentation / rationale.
