# R224B Review Ledger Impact Check

stage_id: 1013R_R224B_ROUTER_FIXTURE_AND_REGRESSION

## Policy

Review ledger may preserve router fields because reviewers need to inspect why a classroom event expansion became light, medium, or heavy.

## Ledger Must Preserve

For each sample:

- lesson_position_in_unit;
- unit_phase_role;
- practice_intensity;
- student_work_time_ratio;
- teacher_support_density;
- performance_task_link;
- stage_evidence_link;
- router_effect.

## Ledger Must Trace

The ledger should show:

1. Why the router value was chosen.
2. Which source evidence or planning assumption supports it.
3. How it changes classroom event density.
4. What evidence the lesson should leave.
5. What teacher confirmation remains required.

## Ledger Must Not Do

The ledger must not:

- become teacher default reading;
- rewrite M/N/O teacher manuscripts;
- publish v0.2;
- trigger runtime;
- expose executable component actions.

## Pass Signal

The review ledger can inspect router reasoning while the teacher default view stays natural and manuscript-like.
