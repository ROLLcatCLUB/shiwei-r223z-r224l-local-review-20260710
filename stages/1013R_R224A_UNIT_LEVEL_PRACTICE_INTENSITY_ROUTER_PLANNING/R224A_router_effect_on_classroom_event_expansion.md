# R224A Router Effect On Classroom Event Expansion

stage_id: 1013R_R224A_UNIT_LEVEL_PRACTICE_INTENSITY_ROUTER_PLANNING

## Purpose

The router does not only label a lesson. It changes what the classroom event expansion should emphasize.

## Effect Matrix

| Router dimension | Low / light effect | Medium / normal effect | High / heavy effect |
| --- | --- | --- | --- |
| explanation_density | Short concept framing and guiding questions | Shared observation plus method explanation | Targeted reminders only, avoid taking over work time |
| demonstration_density | One brief example if needed | Step demonstration or comparison demonstration | Partial / rescue demonstration, not full teacher-made work |
| micro_practice_count | 0-1 | 1-3 | 1-2 only for bottlenecks |
| formal_creation_time | Minimal | Moderate small work or trial outcome | Large block for making, revising, and completing |
| teacher_circulation_focus | Check understanding and participation | Check method use and evidence record | Check task purpose, material choice, collaboration, progress, rescue needs |
| showcase_evaluation_intensity | Quick sharing or naming | Compare evidence and explain method | Structured showcase, self/peer evaluation, performance task contribution |
| learning_sheet_fields | Observation / vocabulary / classification | Prediction / trial / comparison | plan / process / problem solved / reflection |
| evidence_collection_mode | oral or short record | trial sample and learning sheet | process photo, draft, work, explanation, evaluation |

## Role-Specific Effects

### intro_understanding

The expansion should help students notice and name the problem. It should not rush into heavy product-making.

### technique_preparation

The expansion should show the method, let students try safely, and keep evidence of what was learned from the trial.

### practice_creation

The expansion should protect student work time and provide teacher support at bottlenecks. It should not over-explain.

### showcase_evaluation

The expansion should help students use evidence to describe, compare, and evaluate. It should not become empty praise.

### transfer_closure

The expansion should help students connect what they learned to a new context or unit conclusion.

### project_synthesis

The expansion should help students assemble prior evidence into a coherent performance product.

## Guard

R224A must not produce one universal fixed classroom pattern.

The router should change density before classroom event expansion is written.
